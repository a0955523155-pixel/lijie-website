# V6.59｜固定訂金 NT$3,000＋不污染正式資料的測試模式

- 訂金改為固定 NT$3,000，官網與 LINE 新預約自動帶入，不需逐筆設定。
- 官網後台新增「開啟官網測試模式」按鈕；測試網址以 `?test=1` 標記。
- 測試訂單編號加上 `TEST-`，Firestore 中標記 `isTest: true`。
- 測試訂單不鎖正式 availability、不列入後台正式收款／尾款／支出統計。
- 測試訂單可在後台按「模擬訂金 3,000 入帳」，不用真的匯款即可測 LINE 確認流程。
- 後台新增「清除全部測試資料」，會刪除 TEST 訂單與其測試收退款／支出紀錄。
- 測試 Email 會明確標示「測試模式」，避免誤認為正式預約。
- 正式訂單流程維持：送出申請 → 固定訂金 3,000 入帳 → 後台核帳 → 官方 LINE 按確認 → 正式鎖定日期。

部署 V6.59 時請同步發布新版 `firebase/firestore.rules`，否則「清除全部測試資料」會被 Firestore 規則拒絕。
