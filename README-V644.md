# V6.44｜每日價格＋6 個月預約＋台灣連假／墾丁旺季

## 新功能
- 官網與 LINE 預約日曆顯示「每晚價格」。
- 選好入住／退房後即時顯示住宿晚數與預估總價。
- 預設僅開放未來 6 個月，可在後台價格設定改為 1～18 個月。
- 後端送出時再次檢查預約期間，超出開放期間會拒絕，避免繞過前端。
- 後台新增：政府連假價、墾丁活動／跨年旺季價、自動辨識開關。
- 特殊日期優先順序：手動特殊日期 > 墾丁活動／跨年 > 政府連假 > 週五／週六／平日。

## 自動旺季來源與邏輯
- 台灣政府連假：後端嘗試讀取政府公開行政機關辦公日曆資料；連續 3 天以上才視為連假價，避免一般週末被誤判。
- 台灣祭：屏東旅遊網長期活動年曆明載台灣祭每年於 4 月連假、墾丁大灣舉行；系統在抓到官方年曆描述時，將該年度 4 月政府連假標為「台灣祭旺季」。
- 跨年：12/31 與 1/1 固定標為「跨年旺季」。
- 外部官方資料暫時無法取得時，基本平日／週五／週六與手動特殊日期仍可正常計價，不會讓預約失效。

## 後台建議設定
1. 平日、週五、週六價格必填。
2. 政府連假價可設，例如 18,000。
3. 墾丁活動／跨年旺季價可設，例如 20,000。
4. 開放預約月數預設 6。
5. 春節、特殊演唱會、臨時活動等仍可使用「特殊日期價格」人工覆寫。

## Firestore
價格仍儲存在 `settings/pricing`。若後台顯示 `Missing or insufficient permissions`，請確認 Firebase Firestore Rules 已發布本專案 `firebase/firestore.rules`，且登入帳號在 `admins/{uid}` 中。
