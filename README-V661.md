# V6.61｜官網訂單綁 LINE＋LINE 訂單查詢／取消須知

- 修正官網預約成功卻顯示「預約編號 undefined」：只有 API 真正回傳 bookingId 才顯示成功。
- 官網送出成功訊息放大並改為清楚的付款卡式文字。
- 電腦版不再顯示「使用官方 LINE 預約」入口；官網可獨立完成預約申請。
- 官網預約完成後，可選擇到官方 LINE 直接輸入預約編號綁定訂單。
- 一筆訂單最多只能綁定一位 LINE 使用者；已被其他 LINE 綁定時拒絕重複綁定。
- 官方 LINE 新增三個核心功能：立即預約、查詢訂單、取消預約。
- 傳「查詢訂單」會列出目前 LINE 帳號已綁定的訂單；未綁定時會引導輸入官網預約編號。
- 取消預約回覆新增完整須知：必填原因、取消非即時生效、訂金處理不自動判定、正式取消後才釋出日期。
- 固定訂金維持 NT$3,000；訂金入帳後才能由管理者在 LINE 正式確認預約。
