# V6 房間介紹輪播

本版維持單頁網站，不新增獨立房型頁。

## 前台新增
- 「所有房間」大圖輪播區
- 桌機：左右箭頭切換
- 手機：可左右滑動
- 房間進度點與 01 / 07 計數
- 每一間房都有名稱、小標、介紹文字與「查看可預約日期」
- 與既有預約日曆同頁串接

## 後台新增
- 照片管理可直接更換 7 間房的輪播主圖
- 可從本機上傳，或從既有圖片素材庫選擇
- 「文字與資訊」可修改每間房名稱、小標與介紹
- 草稿 / 預覽 / 正式發布流程沿用原本機制

## 舊資料相容
若 Firestore 既有草稿還沒有 rooms 欄位，V6 後台登入後會自動補上預設房間資料，不需要刪除舊草稿，也不需要新增 Firestore Rules。

## 部署
覆蓋 GitHub 專案後，等 Vercel 自動部署完成。若瀏覽器仍顯示舊版，請 Ctrl + F5 強制重新整理。
