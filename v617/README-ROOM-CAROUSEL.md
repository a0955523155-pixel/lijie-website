# V6 房間介紹輪播

本版維持單頁網站，不新增獨立房型頁。

## 前台新增
- 「所有房間」大圖輪播區
- 桌機：左右箭頭切換
- 手機：可左右滑動
- 房間進度點與 01 / 07 計數
- 每一間房都有名稱、小標、介紹文字與「查看可預約日期」
- 與既有預約日曆同頁串接

## 後台新增
- 照片管理可直接更換 7 間房的輪播主圖
- 可從本機上傳，或從既有圖片素材庫選擇
- 「文字與資訊」可修改每間房名稱、小標與介紹
- 草稿 / 預覽 / 正式發布流程沿用原本機制

## 舊資料相容
若 Firestore 既有草稿還沒有 rooms 欄位，V6 後台登入後會自動補上預設房間資料，不需要刪除舊草稿，也不需要新增 Firestore Rules。

## 部署
覆蓋 GitHub 專案後，等 Vercel 自動部署完成。若瀏覽器仍顯示舊版，請 Ctrl + F5 強制重新整理。


## V6.1 房型修正
- 全館固定為 5 間：雙人房 4 間、四人房 1 間。
- 最大容納人數修正為 12 人。
- 每間房新增可編輯「編號」與「別名」。
- 預設別名為一號雙人房～四號雙人房、五號四人房；可在後台自行改成真正房名。
- 舊 V6 草稿若含 7 間房，進入後台會自動整理成 5 間，不需手動刪除 Firestore 資料。


## V6.2 修正
- 後台修改房間別名或編號後，按「發布網站」會自動同步表單內容，不必先另外按「儲存草稿」。
- 預覽也會直接使用目前輸入的新別名。
- 房間編號現在可在後台自訂，不會重新載入後被強制改回預設值。
