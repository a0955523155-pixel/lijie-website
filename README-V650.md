# V6.50｜只留人數選單＋連假住宿夜計價

- 官網與官方 LINE 預約頁移除入住／退房 date input 快速選單，只保留「入住人數」選單；日期一律直接從日曆點選。
- 官網點選的入住／退房日期與人數仍會透過 URL + localStorage 帶入 LINE 預約頁，不需重選。
- 連假價格改成民宿住宿夜邏輯：**隔天仍放假 → 今晚套連假價；隔天恢復上班 → 今晚回一般價**。
- 例：2026/9/25～9/28 中秋連假，連假夜價套 9/24、9/25、9/26、9/27；9/28 晚回平日價。
- 一般週末仍維持週五／週六價；週日晚回平日價。
- 春節、跨年與手動特殊日期仍可由特殊／旺季規則覆寫。
