# V6.43｜日期計價 SOP + 後台價格設定

## 新增功能
- 後台新增「價格設定」：平日（週日～週四）、週五、週六。
- 可新增不限筆「特殊日期價格」覆蓋，例如春節、跨年、連續假期、活動檔期。
- 官網維持不公開固定價格。
- 客戶送出預約時，後端依實際住宿晚數逐晚試算，將總額寫入 booking 並顯示於客戶待確認卡、管理員卡。
- 管理員確認預約後，客戶確認卡會保留該筆試算總額。
- 客戶在 LINE 詢問「價格／價錢／房價／多少錢」時，會引導使用預約日曆選實際日期試算，不直接回一個容易失準的固定價格。

## 計價優先順序
1. 特殊日期價格（後台手動設定）
2. 週五價格
3. 週六價格
4. 平日價格（週日～週四）

退房日不計住宿費，例如 9/25 入住、9/27 退房只計 9/25 與 9/26 兩晚。

## 部署提醒
這版新增 Firestore `settings/pricing` 管理權限，若 Firebase rules 是手動部署，請同步發布 `firebase/firestore.rules`。
