# V6.49 — 官網選單修版＋LINE 選單同步＋連假夜價修正

## 本版修正
- 官網手機版入住／退房日期選擇器改為窄螢幕單欄，避免 iOS/LINE WebView 的 date input 撐破版面。
- 官方 LINE 預約日曆新增與官網一致的「入住日期／退房日期／入住人數／套用到日曆」選單。
- 官網帶入 LINE 的 `start/end/guests` 會同步顯示在 LINE 選單、日曆與表單人數。
- LINE 選單與點選日曆雙向同步。
- 連假價格改為「住宿夜」邏輯：連假最後一天雖仍是官方放假日，但當晚不再套連假價，改回該星期的一般價格。
  - 例：2026/9/25～9/28 為連續假期，連假夜價套 9/25、9/26、9/27；9/28 晚上改回平日價。
